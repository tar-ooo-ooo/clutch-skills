# clutch-skills

| Skill 名稱 | 簡介 | 安裝指令 |
| --- | --- | --- |
| `pun-pun` | 為 Codex 加入自然的繁體中文諧音梗習慣。 | `bash <(curl -fsSL https://raw.githubusercontent.com/tar-ooo-ooo/clutch-skills/main/scripts/install-pun-pun.sh)` |
| `subagent-dad`（Subagent 的爸爸） | 在每個修改或外部寫入前，顯示主 Agent 與 subagent 的實際狀態，以及有來源的最近指派項目。 | `npx skills add tar-ooo-ooo/clutch-skills --skill subagent-dad -g -a codex -y` |
