# clutch-skills

| Skill 名稱 | 簡介 | 安裝指令 |
| --- | --- | --- |
| `pun-pun` | 為 Codex 加入自然的繁體中文諧音梗習慣。 | `bash <(curl -fsSL https://raw.githubusercontent.com/tar-ooo-ooo/clutch-skills/main/scripts/install-pun-pun.sh)` |
| `subagent-dad`（Subagent 的爸爸） | 先用動態 agent 工作表與 Mermaid 決策流程取得確認；確認後才派工或執行，且每次寫入前以表格回報實際狀態。 | `npx skills add tar-ooo-ooo/clutch-skills --skill subagent-dad -g -a codex -y` |
