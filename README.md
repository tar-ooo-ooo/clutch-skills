# clutch-skills

| Skill 名稱 | 簡介 | 安裝指令 |
| --- | --- | --- |
| `pun-pun` | 為 Codex 加入自然的繁體中文諧音梗習慣。 | `bash <(curl -fsSL https://raw.githubusercontent.com/tar-ooo-ooo/clutch-skills/main/scripts/install-pun-pun.sh)` |
| `subagent-dad`（Subagent 的爸爸） | 動態合併已配置 agent 與 live inventory，以工作表和 Mermaid 顯示分工及授權範圍；明確指令可直接執行，只有擴大範圍或未授權外部動作才暫停。 | `npx skills add tar-ooo-ooo/clutch-skills --skill subagent-dad -g -a codex -y` |
| [api-spec](skills/api-spec/SKILL.md) | 依實作撰寫繁體中文 API 規格，統一 Mermaid 決策流程、請求回應表格與資料庫讀寫說明。 | `npx skills add tar-ooo-ooo/clutch-skills --skill api-spec -g -a codex -y` |
| [issue-brief](skills/issue-brief/SKILL.md) | 依指定或確認的分類撰寫精簡工單留言。 | `npx skills add tar-ooo-ooo/clutch-skills --skill issue-brief -g -a codex -y` |
